# SHE PKG — Mine Permit

Aplikasi web SHE PT Hamparan Mulya (Site Muara Teweh): pengajuan & cetak Mine Permit, pas foto otomatis, scan QR pelanggaran.

- Tampilan: HTML + JavaScript statis (GitHub Pages)
- Data, foto & login: Supabase project **SHE PKG**
- Kunci di `js/config.js` adalah *publishable key* (aman untuk web); akses data dibatasi login + RLS di database.

Alamat: https://dovostik.github.io/she-pkg/
